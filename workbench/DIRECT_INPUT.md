# Yue 2.0 · 直接输入版

本版本已移除工作台中的创作对话、修改建议和大模型 API 配置入口，相应服务端接口也已移除。歌曲生成不需要配置外部大模型。

1. 在歌曲手稿中填写音乐风格。
2. 粘贴分段歌词，必要时点击“整理歌词段落”。
3. 点击“生成歌曲”，在下方查看任务和试听结果。

保留原页面配色、双栏、歌词编辑、保存与撤销、音乐规划、ABC 校验、任务状态、版本管理、播放器和下载。右侧原对话区域改为静态创作指南。

生成条件是音乐风格、歌词、可选 ABC 乐谱和生成参数。作品概要、语言、情绪、人声等备注字段继续保存；希望影响音乐的内容应写入手稿中的音乐风格。模式默认 full；生成音乐方案属于 YuE2 推理，不依赖已移除的外部创作助手。

模型自动准备逻辑保持不变，参见 MODEL_SETUP.md。启动、停止和重启：

```bash
bash /root/YuE/workbench/control.sh start
bash /root/YuE/workbench/control.sh stop
bash /root/YuE/workbench/control.sh restart
```

此次验证：40 项测试通过；浏览器实测无歌词生成拦截、歌词整理、保存、刷新恢复和输入校验通过。此次没有重新提交完整歌曲生成任务。

高级设置仅显示生成方式、种子和 ABC 乐谱，保留输入校验按钮。旧项目的笔记和生成参数继续随项目、版本保存，不因界面精简而覆盖。
